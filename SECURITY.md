# Security Policy

If you believe you've found a security vulnerability in Midnight Loadboard,
please report it privately rather than opening a public GitHub issue.

**Contact:** security reports can be sent to [robertariano@gmail.com](mailto:robertariano@gmail.com).

Please include, as much as you're able to:
- Type of issue and affected page/endpoint
- Steps to reproduce
- Potential impact

We'll acknowledge reports as quickly as we can and keep you updated as we
work on a fix.
